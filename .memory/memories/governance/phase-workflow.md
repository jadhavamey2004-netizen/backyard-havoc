Treat each overhaul phase as a separate approved scope. Before work, verify the exact expected main baseline and a clean tree, create the requested `codex/` branch, and read the phase capsule plus exact phase prompt. Do not begin later phases. Use one primary agent for coupled implementation when specified; use subagents only for authorized, independent read-only review. Run the requested checks, push, verify exact-head CI/preview, create a draft PR, and stop at external review. Do not merge without instruction.
