Outfit is requested from Google Fonts at runtime and is not vendored in this repository. Google Fonts metadata identifies Smartsheet Inc. and Rodrigo Fuenzalida as designers, The Outfit Project Authors as copyright holders, and the SIL Open Font License 1.1. See the [Google Fonts Outfit metadata](https://github.com/google/fonts/blob/main/ofl/outfit/METADATA.pb), [Outfit OFL notice](https://github.com/google/fonts/blob/main/ofl/outfit/OFL.txt), and [Outfit source repository](https://github.com/Outfitio/Outfit-Fonts).

The Google Fonts CSS endpoint and `fonts.gstatic.com` serve these fonts to the browser. The project does not package or redistribute font binaries in its production output. See [Google Fonts](https://developers.google.com/fonts) for service and licensing information.
