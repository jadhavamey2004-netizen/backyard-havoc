# Phase 13 authored visual sources

Every SVG under this tree was authored for Backyard Havoc in Phase 13 from the project art brief. No third-party or internet-downloaded image assets are present. These files are editable source; generated runtime copies are produced under `public/assets/generated/` by `npm run build:remaster-assets` and must not be hand-edited.

The renderer spike intentionally uses a small environment/prop sample. Player and Kevin reference SVGs are pipeline placeholders; the Pixi renderer experiment continues to draw their current authoritative animation poses through the existing Canvas character renderers.
